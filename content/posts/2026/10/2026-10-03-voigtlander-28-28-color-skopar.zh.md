# 均衡

{{< img src="/images/2026/10/03/m9p-vm-1.JPG" title="↑VM28 2.8" caption="正面">}}

虽然蔡司近十年在民用光学镜头市场销声匿迹令人唏嘘，但作为蔡司代工厂的确善能福伦达反倒给出了些亮眼的表现，而2023年发布的VM 28 2.8 Color Skopar便是其中之一。其最大的亮点便是高性价比的均衡表现：同时兼顾了一流的做工+小巧的体积+不俗的素质+实惠的价格（比它更小巧的素质都差一截，比它素质更好的体积又大一截，唯一的例外是徕卡28 2.8，但价格却贵几倍）。

{{< img src="/images/2026/10/03/m3-vm.JPG" title="↑VM28 2.8" caption="配M3">}}

# 外观

最近几年福伦达总算是开窍扔掉钢嘴了，新发布的几枚镜头颜值立马提升（莫非当初为了代工ZM镜头，库存里钢嘴买太多了？），甚至还送了配套遮光罩。VM28 2.8分type 1和type 2两种造型，其中type 1还在M口之外细分了LTM螺口的版本，不得不说是用心了。

{{< img src="/images/2026/10/03/m9p-vm-3.JPG" title="↑VM28 2.8" caption="接在M9P上非常小巧">}}

颜值上我更喜欢type 2简约现代的造型，但这个造型直上直下，总觉得少了些设计感，单纯靠体积小巧这点取胜。由于type 2自带月牙扳手，所以黄斑对焦时比捏着我上一枚老佳能28 2.8 LTM窄窄的对焦环方便很多。但如果打算用超焦距区域对焦（选好光圈和预估对焦距离后就不轻易调整镜头了），我反而会更喜欢type 1的设计: type 2的对焦环更大，光圈环也更靠外，扫街盲派/抓拍时其实更容易误触。

{{< img src="/images/2026/10/03/rollei-vm-canon.JPG" title="↑镜头体积对比" caption="禄来Sonnar 40 2.8 LTM vs 福伦达VM 28 2.8 vs 佳能28 2.8 LTM。题外话，禄来有个类似大小的遮光罩是在镜头外缘卡住固定的，滤镜可以同时安装在遮光罩里面；而VM28 2.8的遮光罩是螺纹设计，只能串联叠加UV镜和遮光罩">}}

另外type 2最近对焦距离“优化”到0.5米，但经过0.7米时却没有限位提示，属于"给了"但又“只给了一半”；我觉得还不如像type 1那样老老实实做成0.7米实在。

{{< img src="/images/2026/10/03/m9p-vm-2.JPG" title="↑VM28 2.8" caption="最近对焦距离0.5米但没有限位提示">}}

# 画质

{{< img src="/images/2026/10/03/CL-vm-top.JPG" title="↑VM28 2.8" caption="转接在徕卡CL上，为了体积最小化把遮光罩换成了银色UV镜">}}

VM28 2.8接在数码机上时，锐度和反差都很高，边角画质和眩光控制也相当不错，唯二稍显不足的地方：

1. 影调不如徕卡那枚28 2.8控制得细腻:这枚vm在肩部和趾部过渡区更窄，光比大的画面更容易呈现出死黑死白；
2. 颜色也不如徕卡那么“正”，依然是日福一如既往的偏青绿色（尤其在m9的ccd上有时暗部会偏的非常脏！cmos上偏色还算在正常范围内，问题不大）

另外这枚镜头全开暗角偏大，不过我基本都是F8超焦距使用所以体会不深。主要痛点还是偏色后期比较麻烦。

{{< img src="/images/2026/10/03/cl-vm-2.JPG" title="↑VM28 2.8" caption="在CL上画面颜色更正">}}

# 样片

{{< img src="/images/2026/10/03/40mm.JPG" title="↑40mm爱好者" caption="禄来40 2.8 LTM，宾得FA43 1.9，VM28 2.8转接徕卡CL，理光GR3x HDF">}}

作为标头党，我还是更习惯把VM28 2.8转接在CL上等效42mm的视角，出片率也更高。但这次带着这枚镜头挂在M9P上，确实发现广角+近距离构图时带来的更强烈的视觉冲击力。感觉28mm想要拍出彩，跟被摄主体的距离大概得在1米左右（40mm的镜头我习惯预判3米或更远）。下面的样图都是光圈F8超焦距抓拍。
